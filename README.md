# Business Simulator

A business simulation game built in SwiftUI.

## Current Features

- Product selection
- Inventory purchasing
- FIFO inventory accounting
- Ingredient expiration
- Price-based demand simulation
- Daily financial summaries

## Planned Features

- Multiple product lines
- Equipment options
- Advertising options
- Distribution Options
- Weather
- Financing
- AI business consultant

## Technologies

- Swift
- SwiftUI
